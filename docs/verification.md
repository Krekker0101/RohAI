# Результаты проверки первого этапа

Проверено 13 сентября 2026 года в Windows, CPython 3.14.5, uv 0.11.14.
Python 3.12 проверен на уровне синтаксиса (`ast.parse(feature_version=(3, 12))`);
отдельный runtime Python 3.12 в этом окружении не запускался.

| Проверка | Результат |
| --- | --- |
| Импорты | Четыре namespace и все 14 внутренних модулей импортируются |
| Python 3.12 syntax | Все 24 Python-файла проходят разбор |
| `uv sync --locked --offline` | Успешная синхронизация по lock-файлу |
| `uv pip check` | Установленные зависимости совместимы |
| `uv run ruff check .` | Ошибок нет |
| `uv run ruff format --check .` | Форматирование соответствует конфигурации |
| `uv run mypy` | Strict checking: ошибок нет в 23 файлах приложения и тестов |
| `uv run pytest` | 21 passed, 2 warnings |
| Настоящий HTTP server | `/health/live`, `/health/ready`, `/api/v1/state`, `/docs`: HTTP 200 |
| Остановка HTTP server | Поток сервера завершён, mock закрыт, сигнал all-red |
| Docker | Docker CLI отсутствует; сборка контейнера не проверялась |

Итоговый набор выполнен через:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1
```

Параметр ExecutionPolicy относится только к этому процессу: глобальная политика
PowerShell не изменялась. Отдельные команды `uv run ...` обходятся без `.ps1`.

Два предупреждения исходят из Starlette: переход TestClient с httpx на httpx2 и
устаревший alias `anyio.abc.BlockingPortal`. Тесты не подавляют предупреждения.
HTTP/WebSocket интеграция и проверки завершения проходят с зафиксированными версиями.

Из-за медленной сети часть wheel-файлов была загружена с зеркала PyPI с обязательной
проверкой SHA-256 по `uv.lock`. Lock-файл сохраняет официальные PyPI URL.
Временные инструменты загрузки и пакеты находятся только в игнорируемом `.uv-cache`.

## Измеренный benchmark

Команда: `uv run python scripts/compare.py --seed 42 --duration 600`.
Одинаковые исходный поток, горизонт 600 секунд и шаг 0.5 секунды для обеих политик.

| KPI | Fixed-Time | Smart adaptive |
| --- | ---: | ---: |
| Прибыло объектов | 427 | 427 |
| Обслужено объектов | 311 | 355 |
| Осталось в очередях | 116 | 72 |
| Суммарное ожидание, объект·с | 34 872.29 | 24 394.59 |
| Ожидание на прибывший объект, с | 81.67 | 57.13 |
| Throughput, объектов/мин | 31.1 | 35.5 |
| Максимальная общая очередь | 116 | 80 |

Снижение суммарного ожидания: **30.05%** на этом сценарии. KPI включают транспорт
и пешеходов; ожидание оставшихся очередей учитывается до конца горизонта.
Этот результат не означает гарантированного улучшения на других потоках или
измеренной эффективности на реальном перекрёстке.
