# Проверка распознавания на собственных видео

Для первого ролика уже подготовлены 12 исходных 4K-кадров:
`artifacts/realtime-video-review/annotate.html`. Откройте файл в Edge/Chrome.
Этот инструмент работает локально, без сервера и отправки видео в облако.

1. Обведите видимые машины рамками; для остальных объектов выберите класс.
   Не отмечайте здания как автомобили. Для маленьких объектов увеличьте масштаб.
2. Укажите имя/идентификатор проверяющего. Подтвердите кадр только после проверки
   всех классов в списке. Пустой кадр тоже требует явного подтверждения.
3. Переключайтесь между кадрами. Удаление/добавление рамки сбрасывает подтверждение.
4. Нажмите «Сохранить JSON разметки». Перед закрытием всегда экспортируйте JSON.
   Для продолжения выберите сохранённый файл через «Продолжить из JSON».

Проверка и преобразование в нативную схему проекта:

```powershell
.venv\Scripts\python.exe scripts/import_review_labels.py artifacts/realtime-video-review C:\Users\hp\Downloads\human-labels.json --output datasets/reviews/first-road-labels
```

Выходная папка должна быть новой. Несовместимые видео, изменённые кадры,
невалидные рамки и отсутствие проверяющего отклоняются до создания результата.
Неподтверждённые кадры не экспортируются как отрицательные примеры.

Для других видео:

```powershell
.venv\Scripts\python.exe scripts/prepare_video_review.py "путь-к-видео.mp4" --output artifacts/another-review --count 24
```

Классы редактора: 0 car, 1 bus, 2 truck, 3 motorcycle, 4 bicycle, 5 pedestrian.
Это локальная схема разметки, не номера COCO; перед обучением необходимо явно
сопоставить её с class_mapping набора данных. Не подменяйте классы модели.

12 разрозненных кадров подходят для первичной проверки детекции, но не измеряют
качество tracking/ожидания/очередей. Для этого нужны непрерывные последовательности
и отдельные метки событий. Весь один ролик/сеанс должен оставаться в одном split.
Для независимой оценки нужны другие записи; права и условия съёмки в DatasetSpec
заполняются по фактическим данным. Импорт рамок ещё не создаёт DatasetRelease
и не запускает обучение.

Проверки реализации: 40 Python-тестов (включая существующие dataset contracts),
один Edge-сценарий редактора, Ruff и JS syntax. Браузерные тестовые рамки обозначены
AUTOMATED_UI_FIXTURE_NOT_GROUND_TRUTH и не используются как реальные метки.
