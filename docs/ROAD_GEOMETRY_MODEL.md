# Road Geometry Model

Слой: `traffic_vision.calibration`, `road_geometry`, `state_estimation`.
Детектор выдаёт наблюдения и не знает политику управления. Контроллер получает
`TrafficState` без координат изображения. JPEG/overlay работают после публикации
аналитического состояния; их ошибка не останавливает аналитику.

## Координаты и калибровка

`CameraCalibration` хранит размер исходного изображения, независимые fit/validation
точки, матрицу H и `CalibrationMetadata`: camera ID, version, UTC timestamp,
world frame, единицы, срок действия и измеренные ошибки RMSE/max в метрах.
`RoadPlaneTransform` переводит image pixels через однородные координаты в локальную
дорожную плоскость. Координаты геодезических опорных точек уже заданы в метрах:
дополнительного глобального meters-per-pixel нет.

Используется `Detection.ground_contact`, если его предоставляет источник; иначе
bottom-center bbox — явно приближённый контакт с дорогой. Усечённый границей кадра
bbox без отдельного контакта не даёт метрическую оценку. Высота/углы bbox не
используются для расстояния или длины очереди. Проекция вне convex hull опорных
точек запрещена: экстраполяция за обследованную область не подтверждена.

Homography применима к одной плоскости. Источник обязан подавать rectified кадры
или иметь документированную проверку пренебрежимо малой дисторсии. Код не выполняет
автоматическую коррекцию объектива. Эстакады, заметные уклоны с изломами и смена
zoom/crop требуют другой обследованной геометрии. Основа модели —
[OpenCV: planar homography](https://docs.opencv.org/4.13.0/d9/dab/tutorial_homography.html).

## Дорожная модель

`RoadIntersection`: intersection ID, geometry version, world frame, lanes, crosswalks.
Approach задаётся направлением и объединяет несколько `RoadLane`. Полоса имеет
собственный ID, регион, entry/queue/exit zones, ориентированные entry/stop/exit lines,
centerline по ходу движения и допустимое направление straight/left/right/shared.
`shared` означает неразличённый манёвр, а не предсказанный поворот автомобиля.

Расстояние до стоп-линии — разность chainage её пересечения с centerline и проекции
контакта на centerline; после стоп-линии расстояние отрицательное. Валидация требует
однократного пересечения линий в порядке entry → stop → exit. Полигоны простые,
границы включены. На общей границе сохраняется предыдущая подходящая полоса;
без истории неоднозначное назначение остаётся неизвестным.

В `TrackSnapshot.road_state` и `traffic.estimation.tracks` доступны current_approach,
current_lane, movement_direction, distance_to_stop_line, estimated_speed_mps,
crossed_entry_line, crossed_stop_line, crossed_exit_line, queued и wait_seconds.
Road track UID — каноническая идентичность метрического слоя, отдельная от raw ID.

## Значение метрик

| Поле | Unit | Определение |
|---|---|---|
| queue_vehicle_count | vehicle | Наблюдаемые остановившиеся автомобили в queue zone до stop line |
| queue_length_m | m | Максимум расстояний до стоп-линии среди контактов в очереди; максимум по полосам подхода |
| mean_wait / max_wait | s | Среднее/максимум текущего наблюдаемого эпизода ожидания очереди |
| arrival_rate | vehicle/min | Entry crossings за окно / длительность окна × 60 |
| departure_rate | vehicle/min | Stop-line crossings за окно / длительность окна × 60 |
| throughput | vehicle | Exit crossings с начала непрерывной валидной сессии оценивания |
| occupancy | fraction | Доля полос подхода с хотя бы одним наблюдаемым автомобилем |
| estimated_speed_mps | m/s | Средняя скорость контактов автомобилей подхода между наблюдениями |

Occupancy здесь не является долей площади bbox или стандартной временной
занятостью петлевого детектора. Queue length не включает неизвестный задний свес
автомобиля: физическая длина машины из bbox не восстанавливается. Ожидание до
первого наблюдения неизвестно; выдаётся наблюдаемая часть, не полное время поездки.

Окно rates — до 60 s; в первом кадре rate неизвестен. Остановка подтверждается
после 0.5 s при скорости ≤0.3 m/s. Порог требует проверки на конкретной камере.
При неизвестной геометрии, движении камеры, неоднозначности или потере видимости
значения недоступны (`value: null`, причина), а не равны нулю.

Старые JSON schema 1 читаются; schema 2 допускает `road` и `camera_calibration`.
`meters_per_pixel` сохраняется только для чтения старых конфигураций и не
преобразует измерения. Legacy px остаются диагностикой; реальное управление без
валидного метрического слоя не разрешается. Демонстрационный simulator evidence
не является способом сертифицировать реальную камеру.
