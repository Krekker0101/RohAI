The recording is paced: frame age includes scheduled playback waiting, so these latencies
are not sensor-to-screen latency. Output cadence matches input cadence, with inference the
largest measured processing stage. A 30-FPS real webcam may drop old inference frames;
that remains an intended freshness policy, not a successful 30-FPS measurement.

Implemented resource/performance controls: one local reader, one shared latest capture slot,
bounded stage slots, inference cadence, post-inference age/epoch rejection, bounded reopen,
shared async preview encoder, closed browser ImageBitmaps and exact-frame overlay matching.
Default JPEG publication avoids the old unconditional large debug-panel rendering. New
performance fields measure JPEG/publication, recovery and corrupt/stale frames. No before/after
improvement percentage is claimed because no comparable pre-change run was recorded.

UI paint/network latency, live camera FPS, physical camera-to-ACK, long-run memory stability,
GPU behavior and toy-object inference quality remain NOT_MEASURED. Use fixture mode only
for infrastructure diagnostics; it is explicitly labelled synthetic and is not a YOLO substitute.
