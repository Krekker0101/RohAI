# Оставшиеся ограничения

1. **Физический этап NOT VERIFIED.** Нужны реальный ESP32, схема независимого interlock, аппаратный E-stop, local ARM и наблюдение ламп. Программная FSM/ACK, checkbox и успешная компиляция не заменяют эти испытания.
2. **Vision domain accuracy NOT VERIFIED.** COCO baseline проверен на существующем записанном видео, без ground truth. Нет измеренной точности игрушечных машин/пешеходов, queue MAE и count error. Геометрическая гипотеза не обнаруживает достоверно дорожные границы в произвольной сцене.
3. **Реальная камера NOT VERIFIED в этой приёмке.** IPC, reconnect, stale/corrupt frames и epochs проверены программно; конкретные драйверы/экспозиция/USB/RTSP сети требуют испытаний. Подтверждённая калибровка требует достаточных статических признаков ORB. Поворот/смена источника/разрешения требуют проверки.
4. **Autosetup ограничен.** Камеры проверяются последовательно, индексы 0…10; каждый backend probe ограничен четырьмя секундами, общий поиск может занять минуты. Несколько кандидатов требуют выбора. USB VID не является доказательством ESP32 identity; только protocol ответ проверяет firmware/device/domain. Открытие USB может вызвать DTR reset, даже при IDENTIFY.
5. **Долговременный soak NOT VERIFIED.** Ограниченные очереди и clean shutdown проверены; длительные утечки, native OpenCV/Torch pools, thermal throttling и camera→ACK под физической нагрузкой не измерены. CPU benchmark короткий и многопоточный.
6. **Локальная безопасность.** DPAPI защищает текущего Windows-пользователя; система не защищает от вредоносного процесса под тем же пользователем. HTTP loopback cookies не используют Secure. POSIX fallback хранит digest с mode 0600; основная платформа Windows. Нет удалённого control API или промышленного deployment.
7. **Разрешение управления не сохраняется.** Постоянно сохраняется только просмотр одного браузера на семь дней. Настройка/управление разрешаются на текущий запуск, до восьми часов с запуска сервера. При истечении физическое управление останавливается; для нового разрешения нужен перезапуск. Не подтверждена физическая остановка при host crash/потере питания.
8. **Записи ограничены, без автоматического удаления.** Срок хранения — маркировка истечения. Удаление выбранного закрытого сеанса необратимо и требует подтверждения. Активные/незавершённые записи не удаляются автоматически. При лимите времени/байтов/числа сеансов запись отключается; видео может содержать личные данные. Один write может немного превысить byte limit. Replay загружает части по 200 событий; произвольный seek по всей огромной истории не реализован. Legacy timestamps обозначаются отдельно.
9. **Доступность проверена частично.** Основные кнопки/labels/focus/skip link, клавиатурные координаты и mobile overflow проверены. Полная проверка screen reader, цветов и соответствия WCAG не выполнена.
10. **Firmware host compatibility.** Host требует 1.0.1, firmware 1.0.0 намеренно несовместима с read-only preparation. Обновление реальной платы в этой работе не выполнялось. Результат сборки и её внешние зависимости указаны в приёмочной таблице.

Допустимо показывать DEMO и программные сценарии. Физическую демонстрацию допускают только после документированной аппаратной приёмки; весь RohAI 1.0 сейчас не сертифицирован и не предназначен для городских светофоров.
