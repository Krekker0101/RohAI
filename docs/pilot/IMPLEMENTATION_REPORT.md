## Скорость

Общие Laplacian и resize в health monitor вычисляются один раз на кадр, вместо
повторного расчёта для каждой ROI. Диагностики сравниваются с исходными вычислениями
на шуме, изменении изображения, freeze, чёрных и белых кадрах.
Парный микрозамер: **20.08 → 10.32ms, −48.60%**, 12 ROI, 100 измерений,
результаты checks совпали. Это ускорение конкретных проверок, не всего Vision.

Исходный recorded запуск дал **12.46 FPS**, inference p95 **102.44ms**. Последующие
запуски значительно медленнее: причина изменения условий не установлена.
В восьми последовательных замерах 1/2/4/8 потоков ни один вариант не прошёл
предварительные пороги. Автоматического изменения CPU budget нет; default сохранён.
Устойчивое ускорение полного Vision и устранение регрессии **не подтверждены**.
Все запуски сохранены, включая неудовлетворительные.

## SUMO

Три seeds × четыре политики × 300s; безопасность сигналов проверялась на каждом шаге.
Средние по трём случаям:

| Политика | Цензурированное время остановки / вставленный автомобиль, с | Завершивших маршрут / случай |
|---|---:|---:|
| fixed | 24.17 | 199.33 |
| queue_adaptive | 23.17 | 219.00 |
| queue_pressure | 30.27 | 141.67 |
| sumo_actuated | 20.52 | 226.33 |

Конфликтов сигналов не обнаружено. Fixture включает только прямые автомобильные
движения; это не полевая модель и не исходный PPO benchmark. Одинаковые запланированные
прибытия не означают одинаковые вставленные автомобили при блокировке въезда.
Знаменатель исключает ещё не вставленные source vehicles; остановка не равна полной
транспортной задержке. Три seeds недостаточны для заявления о дорожном преимуществе.
