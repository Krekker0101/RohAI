# Подсветка дорог и процесс анализа

В **Анализе видео** включите **Подсвечивать дороги** и импортируйте запись заново.
В превью появятся голубая полупрозрачная маска и контуры. Рамки транспорта и ID
рисуются поверх маски, чтобы объекты оставались заметными. Старые отчёты не меняются.

Используется предобученная NVIDIA SegFormer-B0 / Cityscapes. В обычном режиме
маска получается из нейросетевого класса `road` с порогом вероятности 0.35.
Для режима дрона добавлено экспериментальное уточнение крупнейшей связной поверхности
по признакам цвета; оно требует пересечения с дорожной маской нейросети.
Это явно подписанная эвристика, а не обученная модель дорог с дрона. При отсутствии
нейросетевых дорожных областей алгоритм не рисует выдуманную дорожную сеть.

Маска обновляется по времени записи примерно раз в секунду и на последнем кадре.
Панель показывает время маски и долю кадра, а отчёт — модель, закреплённую ревизию,
метод и число запусков. В движущейся съёмке маска между обновлениями может отставать;
обочины, парковки, тени и покрытия других цветов могут распознаваться неверно.
Это подсветка для наблюдения, не подтверждённая геометрия дороги или калибровка управления.

На текущем устройстве модель установлена. Для новой установки:

```powershell
uv sync --locked --all-extras
.venv\Scripts\python.exe scripts/fetch_road_model.py
```

Скрипт использует закреплённую официальную ревизию, проверяет SHA-256 всех файлов
и преобразует проверенные веса через `weights_only=True` в safetensors. Worker
проверяет файлы до загрузки и не скачивает модели во время анализа. Отсутствующая
модель не заменяется незаметно другим алгоритмом: выключите опцию или установите её.
Пути: `STA_VIDEO_ROAD_MODEL_DIRECTORY` и `STA_VIDEO_ROAD_MANIFEST_PATH`.
API: параметр `roads=true` при импорте. Без параметра он выключен для совместимости.

Во время работы отображаются вращающиеся индикаторы, волны и сканирующая полоса.
Счётчики и проценты приходят из backend; анимация не увеличивает процент самостоятельно
и не изображает внутренние мысли модели. При завершении, ошибке, отмене или ошибке
получения статуса она исчезает. Настройка ОС «уменьшить движение» отключает анимацию.

Модель уже обучена на Cityscapes; на предоставленном видео новые веса не обучались.
Для такого дообучения нужны проверенные пиксельные маски дорог и отдельные записи
для проверки. Двенадцать ранее подготовленных кадров остаются неразмеченными.

Источники: [официальная модель NVIDIA](https://huggingface.co/nvidia/segformer-b0-finetuned-cityscapes-1024-1024),
[семантическая сегментация Transformers](https://huggingface.co/docs/transformers/tasks/semantic_segmentation).



## Оптимизация CPU

Offline-aerial использует до 6 потоков CPU, не больше половины логических процессоров.
`STA_VIDEO_CPU_THREADS=0` выбирает бюджет автоматически; 1–32 задаёт его явно.
Все кадры обрабатываются. Превью рисуется в ширине до 1280 пикселей.
Маска ограниченно восстанавливает соседний асфальт и небольшие замкнутые пробелы;
ошибки по краям остаются возможными.
